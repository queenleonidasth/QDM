Zen Download Integration

Zen เชื่อมต่อ QDM อัตโนมัติผ่านตัวช่วยในเครื่อง และเชื่อมต่อใหม่ได้หลังรีสตาร์ตโดยไม่ต้องกรอกรหัส

ตั้งค่าด้วยตนเอง (เฉพาะเมื่อการเชื่อมต่ออัตโนมัติใช้ไม่ได้)

เปิด QDM → ⋯ → เชื่อมเบราว์เซอร์ เพื่อดูรหัสจับคู่และพอร์ต
QDM ต้องเปิดอยู่ หาก QDM ไม่ตอบรับ Zen จะดาวน์โหลดต่อเองตามปกติ
หากรวบรวม session เปิดอยู่ QDM จะได้รับคุกกี้ของ URL ที่ดัก หน้าอ้างอิง และ User-Agent ผ่าน localhost โดยเก็บไว้ในหน่วยความจำเท่านั้น ไม่เขียนลงประวัติ — ปิดตัวเลือกนี้หากไม่ต้องการให้ส่งคุกกี้
