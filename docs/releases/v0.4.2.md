# QDM v0.4.2

Release date: 2026-11-08

## Changes since v0.4.1

- Recheck completed files on disk independently of engine activity to prevent stale "File missing" status, with a saved-directory fallback.
- Replace the completed-row "Open file" action with "Show File" to reveal the file in File Explorer.
- Keep active-transfer and completion notifications in the Windows always-on-top band without activating the main window.
- Switch the compact notification progress indicator from download bytes to actual file assembly bytes during merging, with an indeterminate state when totals are unknown.
- Align the "Select all" action vertically with the Downloads row label.
- Carry forward startup-to-tray handling and selection-control layout changes.
- Update Chromium and Firefox/Zen extension package versions to 0.4.2; extension behavior is otherwise unchanged.

## Validation

- Rust unit test suite and Windows x64 release build succeeded on the development PC.
- Full historical multi-suite release acceptance gates were not rerun for this exact build. Treat this as a functional update rather than a fully requalified major release.

## Artifacts

- Windows x64 portable ZIP and Windows x64 NSIS installer.
- Chromium extension ZIP and Firefox/Zen XPI.
